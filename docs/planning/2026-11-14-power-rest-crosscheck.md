**What it shows.** (1) *Cells*: the POWER Zarr archive we read holds the same values as the REST API NASA publishes, cell by cell. **Pass rule (fixed before the first run):** area-mean r >= 0.999 and mean absolute difference <= 2% of the series' SD.

**Cell differences are expected and small.** REST months are in local solar time, the Zarr store in UTC, so a few hours at each month boundary fall in a different month; REST also rounds to 2 decimals.
