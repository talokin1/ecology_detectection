# UI/UX Review: Невідповідності реального сайту плану v2

Після перевірки поточної версії сайту на основі синтетичних даних, виявлено низку відхилень від затвердженого макета та правил `План v2`. Нижче наведено перелік того, що виглядає негарно, незрозуміло для звичайного користувача (Learner) або порушує візуальні гайдлайни.

## 1. Карта та Палітри (Критично)

* **Неправильні кольори для опадів:** На макеті для `Precipitation` використовується коричнево-бірюзова палітра, що відповідає `BrBG`. Згідно з правилами плану, кольори мають чітко розрізнятися за змістом даних. Хоча для води/ґрунту це логічно, варто впевнитися, що це не плутає користувача при перемиканні між змінними.
* **Візуальний шум від температури:** Для `Air temperature` використовується палітра `RdBu`. На карті майже вся площа залита агресивним суцільним червоним кольором. Це створює надмірний візуальний шум ("кривава пляма"), через який неможливо розгледіти крапочки значущості (stippling).
* **Грубі рамки регіонів:** Рамки навколо розслідуваних регіонів (наприклад, "Great Plains", "Ukraine", "Sahel") зроблені товстими чорними лініями з білими плашками-підписами. Вони перекривають самі дані на карті і виглядають занадто грубо. На оригінальних макетах рамки були тонкими і делікатними.
* **Перевантаження карти підписами:** Білі плашки з числовим текстом (наприклад, "Northern Europe +0.05 mm/day per decade") розкидані по всій карті, що дуже перевантажує екран на старті.

## 2. Навігація та Каталог

* **Зайві елементи:** На вкладці `Catalog` під кнопками вибору теми відображається текст "21 variables". Цього лічильника не було в початковому макеті, для звичайної людини він не несе користі.
* **Тьмяні кнопки "Planned":** У таблиці каталогу навпроти багатьох змінних стоїть тьмяний напис "Planned" замість кнопки "Explore ->". Навіть якщо це демо-версія, візуально це виглядає як заблокований інтерфейс або помилка.

## 3. Сторінка Methods (Текстове наповнення)

* **Забагато суцільного тексту:** Сторінка перевантажена масивними блоками тексту. Для пересічної людини це виглядає як підручник, а не як простий допоміжний інструмент.
* **Математичний шум:** Прямо у відкритому тексті (розділ "The trend test") залишені складні формули: `slope = median...`, `Var*(S) = ...`. Згідно з початковою концепцією, такі академічні деталі мають бути приховані (наприклад, під розкривним меню "Geek Details") або показуватися лише за запитом, щоб не лякати користувача.
* **Глосарій:** Визначення термінів (наприклад, "p-value", "False discovery rate") все ще написані занадто академічно і можуть бути незрозумілими для школяра.

## Що необхідно зробити (Action Items):

1. **Зменшити інтенсивність кольорів на карті:** Відкалібрувати палітри (особливо червоний колір для температури), щоб крапочки значущості добре читалися на фоні.
2. **Полегшити рамки:** Зробити межі досліджуваних регіонів тонкими (1 px) і, можливо, напівпрозорими.
3. **Сховати формули:** Прибрати "сухі" формули з відкритого тексту на сторінці `Methods`, сховавши їх під спойлер або кнопку.
4. **Прибрати технічний шум із карти:** Перенести точні числові показники з білих плашок на карті безпосередньо у бічну панель розслідування (Verdict Card).
